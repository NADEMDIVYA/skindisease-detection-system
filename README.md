Skin diseases affect millions worldwide, requiring timely and accurate diagnosis for effective treatment. This project presents an AI-driven Skin Disease Detection System using Deep Learning and OpenVINO to classify various skin conditions. The system is deployed as a web application using Streamlit, allowing users to upload skin images for real-time analysis. It predicts the disease and suggests suitable medications for treatment. By leveraging TensorFlow and optimized inference techniques, the model ensures high accuracy and efficiency. The user-friendly interface makes it accessible on both mobile and desktop devices, enhancing telemedicine and self-assessment. This innovation aids early detection, improves patient awareness, and supports dermatologists in clinical decision-making.The system bridges the gap between AI and healthcare, offering a fast, reliable, and accessible dermatology assistant.
